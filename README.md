# Панель методиста — JavaScript MVP

Статический сайт на HTML, CSS и JavaScript. Подходит для публикации на **GitHub Pages** — Python, сервер и установка зависимостей не требуются.

## Возможности текущей версии

- Импорт `.xlsx`, `.xls` и `.csv` непосредственно в браузере.
- Инвентаризация листов: название, приблизительное количество строк/столбцов, предварительная категория.
- Предварительный просмотр первых строк с простым маскированием колонок, названия которых похожи на чувствительные.
- Поиск и фильтры по листам.
- Экспорт карты листов в CSV.
- Локальный список задач в памяти текущей сессии.

## Запуск локально

1. Скачайте/распакуйте папку проекта.
2. Откройте `index.html` в современном браузере.
3. Для чтения Excel нужен интернет, потому что библиотека SheetJS загружается с CDN.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `metodist-mvp`.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `app.js`, `README.md` и `.gitignore`.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Дождитесь публикации. GitHub покажет URL сайта в разделе Pages.

## Конфиденциальность и ограничения

- Файлы Excel обрабатываются в браузере; код приложения не отправляет содержимое книг на сервер и не сохраняет их в репозитории.
- Не публикуйте исходные рабочие Excel-файлы в GitHub.
- Маскирование в предпросмотре — вспомогательная мера, а не гарантия обнаружения всех персональных данных. Не загружайте особо чувствительные файлы на общедоступные устройства.
- Задачи не синхронизируются между устройствами и не сохраняются после перезагрузки страницы.
- Категории листов определяются эвристически по названию и не являются проверенными бизнес-метриками.
- Эта версия пока не вычисляет достоверные показатели оттока, посещаемости, численности или финансов. Для этого требуется отдельная проверка структуры и правил расчёта исходных книг.
- GitHub Pages публикует сайт публично, если репозиторий/настройки не предусматривают иной доступ. В приложении нет авторизации, поэтому не используйте его как защищённое хранилище.

## Файлы

- `styles.css` — оформление и адаптивная вёрстка.
- `app.js` — импорт Excel, таблицы, фильтры и задачи.

# Методист — ежедневная рабочая система

MVP создан на основе структуры пяти Excel-книг, которые были доступны при сборке:
- Елабуга.xlsx — 53 листа
- Краснодар.xlsx — 17 листов
- Казань.xlsx — 42 листа
- Пермь.xlsx — 46 листов
- Еженедельный отчет.xlsx — 27 листов

Всего: **185 страниц/листов**. В репозитории хранится только названия листов, города, категории и размеры. Реальные строки, ФИО, телефоны, зарплатные и банковские данные не включены.

## Основные функции
- Расписание занятий с городом, локацией, датой, временем, группой, тьютором, ассистентом и модулем.
- Проверка пересечений тьютора, ассистента и локации по времени.
- Задачи и мероприятия: ответственный, город, срок, приоритет, статус, комментарий.
- Карточки групп: расписание, локация, тьютор, наполняемость, лимит, модуль.
- Справочник сотрудников без банковских реквизитов.
- Реестр всех 185 листов и импорт исходных Excel-книг.
- Редактирование ячеек загруженной книги и экспорт обновлённой книги.
- Переменные с именованными ключами, например `{{город}}`, `{{тьютор}}`, `{{группа}}`, с привязкой к столбцам.
- Экспорт расписания, задач, групп и сотрудников в Excel.
- Резервная копия рабочих записей в JSON и восстановление из JSON.

## Запуск локально
Открой `index.html` в браузере. Интернет требуется для загрузки библиотеки SheetJS из CDN при импорте/экспорте Excel.

## Публикация GitHub Pages
1. Создай репозиторий на GitHub.
2. Загрузи файлы проекта в корень репозитория.
3. Открой Settings → Pages.
4. Выбери Deploy from a branch → `main` → `/(root)` → Save.

## Важные ограничения
- Расписание, задачи, группы, сотрудники и словарь переменных сохраняются в `localStorage` текущего браузера. Это не облачная база и не синхронизируется между устройствами.
- Загруженные Excel-файлы держатся в памяти вкладки и не сохраняются на сервер. После перезагрузки страницы книги нужно загрузить снова.
- При изменении/экспорте листов сложные формулы, макросы, форматирование, объединения и диаграммы могут потеряться. Сохраняй оригиналы и проверяй результат.
- Проверка расписания выявляет совпадения по точному имени тьютора/ассистента/локации и пересекающемуся времени. Она не учитывает дорогу, подготовку, часовые пояса и другие бизнес-правила.
- Переменные — это словарь и привязка столбцов; это ещё не автоматическая синхронизация одной сущности между всеми листами.
- Импорт старых книг не заполняет автоматически справочники групп/сотрудников и расписание: исходные листы имеют разную структуру. Для безопасной миграции нужно отдельно настроить правила извлечения.

## Конфиденциальность
Не добавляй Excel-файлы с персональными или банковскими данными в публичный GitHub. GitHub Pages не является защищённым хранилищем. `localStorage` не шифрует данные; используй только на доверенном устройстве. Для полноценной облачной системы понадобятся серверная БД, аутентификация, права доступа, шифрование и резервное копирование.

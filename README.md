# Методист — рабочая система на JavaScript

Это не просто дашборд: это браузерный редактор загруженных Excel-книг. Он позволяет открывать листы, менять значения ячеек, добавлять строки и столбцы, искать текст и выгружать изменённые книги в `.xlsx`.

## Запуск
- Открой `index.html` в браузере; либо опубликуй проект через GitHub Pages.
- Нужен интернет для загрузки библиотеки SheetJS с CDN.
- Нажми «Загрузить Excel» и выбери свои исходные книги.

## GitHub Pages
Загрузи файлы проекта в корень репозитория → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Важные ограничения текущего MVP
- Данные существуют в памяти текущей вкладки до выгрузки; перезагрузка страницы сбрасывает несохранённые изменения.
- Экспорт создаёт новую книгу из данных листов. Сложное форматирование, формулы, макросы, объединённые ячейки, диаграммы, проверки данных и другие расширенные функции исходного Excel могут не сохраниться полностью. Проверяй выгрузку перед использованием как официального документа.
- При редактировании ячейки значение сохраняется при потере фокуса (Tab/Enter/клик вне ячейки).
- Нет пользователей, авторизации, облачной синхронизации или серверной базы.
- Все листы исходной книги показываются как редактируемая сетка; это универсальный редактор, но не полноценный Excel со всеми его возможностями.
- Рабочие книги могут содержать персональные данные и банковские реквизиты. Не загружай исходники в GitHub. Сайт не отправляет содержимое файлов на сервер, но GitHub Pages обычно публикует код публично. Не используй общедоступный компьютер.

## Состав
- `index.html` — интерфейс.
- `styles.css` — адаптивный дизайн.
- `app.js` — импорт, редактирование и экспорт книг.
- `.gitignore` — исключение рабочих таблиц.

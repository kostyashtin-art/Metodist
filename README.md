# Методист — единая система (MVP)

Статический сайт на HTML/CSS/JavaScript, подготовленный по структуре **80 листов** из двух предоставленных Excel-книг:
- «Елабуга.xlsx» — 53 страницы;
- «Еженедельный отчет.xlsx» — 27 страниц.

В репозитории находятся только названия листов, категории и размеры. **Реальные строки, имена, телефоны, паспортные и банковские данные из Excel не включены.**

## Что реализовано
- Страницы по каждому листу двух книг с навигацией и поиском.
- Загрузка обеих книг локально в браузер.
- Просмотр и редактирование ячеек.
- Добавление строк и столбцов, добавление записи через форму.
- Сопоставление столбцов с именованными переменными, например `{{фио}}`, `{{город}}`, `{{тьютор}}`.
- Сохранение словаря переменных в localStorage браузера.
- Экспорт изменённой книги обратно в `.xlsx`.

## Запуск
Открой `index.html` или опубликуй файлы через GitHub Pages. Для импорта/экспорта Excel требуется интернет для загрузки SheetJS CDN.

## GitHub Pages
Загрузи файлы в корень репозитория → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Ограничения MVP
- Данные Excel обрабатываются локально в браузере; серверной БД, входа и синхронизации нет.
- Экспорт/редактирование пересобирает затронутый лист и может потерять оформление, формулы, макросы, объединённые ячейки и другие сложные Excel-объекты. Сохраняй оригиналы и сверяй экспорт.
- Переменные пока задаются для отдельных колонок отдельных страниц; они не обеспечивают автоматическую синхронизацию одной записи между всеми листами.
- Данные не сохраняются между перезагрузками страницы; после работы выгружай книгу.
- `localStorage` содержит только настройки переменных, но всё равно не предназначен для хранения секретов.

## Безопасность
Не загружай Excel-файлы в GitHub и не включай их в коммиты. GitHub Pages обычно публичен. Для постоянной работы с персональными и банковскими данными понадобится отдельный защищённый backend, аутентификация, права доступа, резервное копирование и журналирование.

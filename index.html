НАСТРОЙКА ДАННЫХ

Переменные

Назначь понятные имена колонкам. Настройки хранятся в этом браузере.

Глобальные переменные

Примеры имён: ФИО, город, тьютор, группа, дата, причина_оттока.

Переменная — это имя поля, связанное с конкретной колонкой листа. Она не изменяет структуру исходного Excel, пока ты не выгрузишь книгу.
ИМПОРТ И СОПОСТАВЛЕНИЕ

Подключить Excel

Выбери обе исходные книги. Файлы читаются в браузере и не загружаются на сервер.

Что будет после импорта

Страница с совпавшим названием станет редактируемой. Структура страниц остаётся доступна и без файлов.

  • Все листы будут доступны через левое меню.
  • На каждой странице можно назначить переменные для столбцов.
  • Можно редактировать ячейки, добавлять строки и создавать запись по форме переменных.
  • Экспорт создаёт обновлённую Excel-книгу.
Важно: исходные книги содержат персональные и банковские данные. Не публикуй их в репозитории GitHub. Архив сайта содержит только названия листов, размеры и структуру — не исходные записи.
РАБОЧАЯ СТРАНИЦА

Страница

Подключи исходную книгу, чтобы редактировать данные.

Подключи соответствующую книгу в разделе «Импорт Excel».
Добавить запись

Поля строятся на основе переменных, назначенных столбцам.

Сначала назначь переменные на вкладке «Переменные и колонки».
Сопоставление колонок и переменных

Укажи человекочитаемое название и ключ переменной для каждой колонки.

Пример: колонка C → название «ФИО ученика» → переменная фио. В формах она станет полем «ФИО ученика».
